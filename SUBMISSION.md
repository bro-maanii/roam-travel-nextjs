# Frontend Developer Technical Assessment

**Project:** Roam — Travel Agency Website

- **GitHub repository:** https://github.com/bro-maanii/roam-travel-nextjs
- **Live website (Vercel):** https://roam-travel-nextjs.vercel.app
- **Setup and project documentation:** [README.md](README.md)
- **Single-file submission:** [Roam-Assessment-Submission.pdf](submission/Roam-Assessment-Submission.pdf)

Built using Next.js App Router, TypeScript, Tailwind CSS, and GSAP. Includes all four services, working mock searches, destination browsing, testimonials, contact form, footer, responsive layouts, and the required animations.

Launch features include per-page metadata, canonicals, structured data, social-share image, favicon set, robots.txt, sitemap.xml, 404/loading/error screens, thank-you page, privacy/terms pages, consent-gated analytics and a sticky mobile CTA.

Verification covers 7 unit tests and 13 browser tests, including responsive widths from 320px to 1440px, search/enquiry workflows, metadata, crawl files, contact validation, consent and accessibility.

The PDF includes clickable live website and repository links and is below the assessment's 10 MB upload limit. Travel searches use sample data. Email enquiries are delivered through configured Resend or SMTP credentials to emanaliabbasi99@gmail.com. See the README for setup; the form displays a useful error if mail delivery is not configured.
